## 无问题抽样

- **跨公司 4（MCP）**：`tools/list` / `resources/list` / `prompts`、JSON-RPC 2.0、stdio 与 Streamable HTTP 均与 MCP 规范一致；把 MCP 定位为“工具与 agent 框架解耦 + 运行时发现”，没有与 function calling 混淆。
- **Apple 1（约束解码）**：token 掩码必须 token 感知（一个 token 可跨语法边界）、语法在构建期编译、语法合法≠语义合法、全掩码时需确定性兜底——四点与 constrained decoding 的实际实现相符。
- **Harvey 1（OOXML 修订）**：`w:ins`/`w:del` 才是 Word 的真实修订痕迹；保留 `rsid`、span 匹配要先拼接 run 文本再映射回 run，与 docx 结构一致。
- **京东 5（Spring AI / LangChain4j）**：Spring AI 1.0 的 `CallAdvisor`/`AdvisorChain`、`@Tool` 反射生成 schema，LangChain4j 的 `AiServices` + `@Tool`，都对得上各自实际 API。
- **美团 1（训练配比）**：六个切片 40+20+15+10+10+5=100，且“每个合成调用必须执行并校验”与工具学习的数据构造实践一致。
