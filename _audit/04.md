## 无问题抽样

- 跨公司通用 15：8k/70B 的 KV 2.6 GB 正确；900 GB/s → 2.9 ms、50 GB/s → 52 ms、12.5 GB/s → 208 ms，与文中 3 / 50 / 210 ms 全部对得上，「超过 TTFT 预算 10–15% 就别拆」的判据自洽。
- xAI 1：2×80×8×128×2 = 327,680 B = 320 KiB；×131,072 = 40 GiB；8 条并发 = 320 GiB，逐项复算无误。
- Apple 3：2×28×(8×128)×4096×2 = 469,762,048 B = 448 MiB；换 32 个 KV 头正好 4× = 1.75 GiB，公式与结论一致。
- 美团 2：128 KiB/token 正确；8k × 100 并发 = 100 GiB，与「决定 batch 的是这个数不是 FLOPs」呼应，无小数点错位。
- Groq 2：70 GB / 230 MB = 305 片（≥305 正确）；230 MB / 80 TB/s = 2.9 µs；「320 卡、单流很亏、按卡时算账」的推演自洽。
- Together 3：3000 tok/s × 3600 = 10.8 M；$20 / 10.8 M = $1.85；÷60% 利用率 = $3.1，与「$3–6」报价区间一致。
