## 怎么用

- 面试前：按候选人简历命中的方向挑 **1~2 个题型文档**，再在「按公司找题」里看目标公司考过什么。
- 面试中：**不要全问**，一次挑 5~8 题；`速记` 行是问完给提示用的。
- 面试后：在该题下方追加 `> 实测：候选人在 X 上答不出 O(1) 空间的双指针，给出提示后能补完` 之类的观察。

## 一道题长什么样

```md
### 3. 结构化输出与函数调用有什么区别？

**Asked at**: Mistral AI · Apple · 京东 · 美团
**Source**: https://outcomeschool.com/blog/how-does-function-calling-work-in-llms

**参考答案**

（一句话结论 → 表格/机制分解 → 取舍与失败模式 → 何时别用）

**速记**：结构化输出约束「答案格式」，函数调用是「多轮协议」；模型从不执行代码。
```

- `<!-- EN: ... -->`：英文原题，可折叠放在题号下方，渲染时不可见，用于与出处核对
- `Asked at`：源里标注的出处公司（有的题没有，整行省略）
- `Source`：原始博客/文章链接，按原样保留（有的题没有，整行省略）
- `速记`：一行中文，问完卡住时给提示用
